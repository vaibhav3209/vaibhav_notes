## Deploy:

1. See changes on LOCAL server once. 

     ```bash
     mkdocs serve
     ```

2. Open in GIT BASH in parent `Notes/` folder.


3. Use command in `Notes/` directory where `deploy.sh` file is present. 

    ```bash
    bash deploy.sh <remote-name> "commit message"
    ```
